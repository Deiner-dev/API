API Catálogo de Juegos

Documentación oficial de la API REST desarrollada con Spring Boot y MongoDB.

Tecnologías

  • • Spring Boot
  • • Java
  • • MongoDB
  • • Maven
  • • REST API
  • • Postman

Base URL

http://localhost:8080

Endpoints CRUD

GET /juegos

Obtiene todos los juegos registrados.

GET /juegos/{id}

Obtiene un juego por ID.

POST /juegos

Crea un nuevo juego.

PUT /juegos/{id}

Actualiza un juego existente.

DELETE /juegos/{id}

Elimina un juego.

Ejemplo JSON

{
  "nombreJuego": "Minecraft",
  "genero": "Sandbox",
  "anioLanzamiento": 2011,
  "activo": true,
  "descripcion": "Juego de construcción y supervivencia.",
  "plataforma": "PC",
  "desarrolladora": "Mojang"
}

Modelo de Datos

Campo Tipo Descripción
id String ID generado automáticamente por MongoDB.
nombreJuego String Nombre del videojuego.
genero String Género del juego.
anioLanzamiento int Año de lanzamiento.
activo boolean Estado del soporte y actualizaciones.
descripcion String Descripción del videojuego.
plataforma String Plataforma disponible.
desarrolladora String Empresa desarrolladora.
